# El Pachax — Credit & Debit Ledger

A simple debt ledger app inspired by Credit/Debit Ledger apps.

## Core idea
Each person has an account. Record the debt amount, payments, remaining balance, and optionally the goods involved in the transaction (for example `50 kg watermelon`). Person notes can store an address or any additional information.

## Planned features
- People/accounts
- Credit (debt) and payment/debit transactions
- Automatic remaining balance
- Optional goods description
- Person notes/address/additional information
- Transaction notes
- Search and transaction history
- Google sign-in
- Firebase cloud sync across multiple phones
- Export/backup to Google Drive
